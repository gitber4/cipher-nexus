## 📌 Описание

**Cipher Nexus** — это революционное приложение для побуквенного шифрования текста с использованием замены каждого символа на уникальный трёхзначный код.

### 🔑 Ключевые особенности:

- ✅ **163+ символов** в алфавите (буквы, цифры, спецсимволы)
- ✅ **729 возможных кодов** (9³ комбинаций)
- ✅ **Динамический разделитель** (генерируется через seed)
- ✅ **Ключ миграции** (40 символов для синхронизации)
- ✅ **Обратная совместимость** (миграция из старых версий)
- ✅ **Стойкость 1536+ бит** (эквивалент AES-1536)
- ✅ **Время взлома: 10⁴³⁹+ лет** 🔒
